Connexion

Collez un jeton d'accès GitHub autorisé à modifier le dépôt. Il n'est ni enregistré ni envoyé ailleurs qu'à GitHub, et il est oublié quand vous fermez la page.

Dépôt modifié :

Créer un jeton
  1. Ouvrir GitHub → Fine-grained tokens.
  2. « Repository access » : « Only select repositories », puis choisir .
  3. « Permissions » → « Contents » : « Read and write ». Rien d'autre.
  4. Choisir une date d'expiration, créer le jeton et le copier.
